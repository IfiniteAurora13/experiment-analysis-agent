# BC006：数据完整，方法仍可能不适用

来源：合成数据受控消融，不是生产事故。每组仅 2 名用户，对照 0 人支付、实验 2 人支付，GMV 持平。

## 复现

禁用新增的稀疏事件检查时，既有 pooled z-test 可返回小于 0.05 的 p 值，Wald 差值区间也看似明确；流程会给出“建议小流量灰度或继续推进发布评审”。这不是在当前小样本下可依赖的近似证据。

启用方法适用性检查后，质量门禁 FAIL，评审 BLOCKED，停止效果解读并交实验分析负责人。

[前后原始记录](evidence/BC006_sparse_conversion.json)

运行 python -m evals.replay_sparse_conversion 可复现；before 仅禁用这项新检查，其他代码与输入一致。

## 产品调整与取舍

- 当前本地 z-test / Wald 方法保守要求每组支付和未支付人数均至少 5。
- 这只是拒绝不适用输入的工程边界，不是功效或误差率保证。
- 数据完整只说明记录可以解释，不能证明统计方法适用。
- 不横向增加精确检验、贝叶斯或序贯方法；交分析负责人选择已有可靠方案或新实验计划。
- 不通过延长到显著或事后修改阈值恢复发布建议。

回归：C032 验证水位齐全且零事件时仍阻断当前统计解释；tests/test_review_gate.py 验证极端小样本不能被当作可推进证据。
